ROWLTab is a Protégé plugin that converts SWRL rules into OWL axioms, making rule-based ontology modeling more accessible. Like OWLAx, it has become a popular tool in the Semantic Web community.

Open source: [github.com/md-k-sarker/ROWL](https://github.com/md-k-sarker/ROWL)
