ECII is a knowledge-graph-based data analysis tool for efficient concept induction over description logic knowledge bases. It was pivotal in securing roughly $1 million in funding from DARPA and AFRL, and implements the methods introduced in ["Efficient Concept Induction for Description Logics"](/publications/#sarker2019efficient) (AAAI 2019).

Open source: [github.com/md-k-sarker/ecii](https://github.com/md-k-sarker/ecii)
